## Failures, fixes, retests (not hidden)

1. First browser run: 17 passed, 4 failed. Assistant/export selectors were test-harness errors (wrong label/tab/exact arrow name); corrected to actual accessible UI labels and targeted retests passed.
2. Real microphone bug: unfinalized WebM has no format duration. Added bounded ffprobe packet-timestamp fallback (10,000-packet ceiling); actual synthetic-recording import now passes.
3. Real offline bug: first page/assets were not precached; then Vary: Origin mismatched fetch modes. Added build-time shell precache manifest and ignoreVary **only for same-origin public non-API assets**. Initial retest still failed; second fix plus actual offline render now passes.
4. Real image thumbnail bug discovered by added PIP test: seeking 0.2s in a one-frame still skipped its only frame. Image thumbnail now reads frame zero; actual PIP export/pixel regression passes.
5. A resource-constrained test worker was SIGKILLed while handling verbose serialized byte arrays. Binary transfer in the successful-relink test changed to base64; final full 26-case local/public runs passed with no retries. This is not a guarantee against OOM on every device.
6. Corrupt-backup harness expected capital “Backup” while the real safe rejection was “Invalid backup ZIP”; fixed case-insensitive assertion, without weakening format/CRC/security behavior.
7. UI/bounds hardened for local mode: effect/color/text values validated before FFmpeg, codec/render quotas explicit, jobs cancel by terminating worker, original media retained on failed relink/restore. Backup ZIP accepts only bounded stored entries, validates CRC and safe filenames and rejects compression/encryption/duplicates.

First-run logs, screenshots, contexts and ledger are retained. Four traces have duplicate public engine/sample resources deduplicated to limit package size; their trace events/screenshots remain, and `scripts/restore-trace-assets.py` restores the identical resources from built assets. Do not describe these compact traces as unmodified originals.
